**Owner:** Duy (TV3) | **Reviewer:** Uyên | **Task:** T16
**Đây là "xương sống" — mọi kết quả EXP01–04 phải tuân theo protocol này.**

## 1. Môi trường

| Thành phần | Giá trị |
|---|---|
| Docker network | `shopnet` (bridge) |
| MongoDB image | `mongo:6` |
| Nodes | `mongo1`, `mongo2`, `mongo3` — mỗi container 1 node |
| Replica set name | `rs0` |
| Connection string | `mongodb://mongo1:27017,mongo2:27017,mongo3:27017/?replicaSet=rs0` |
| Database / collection | `shop.products`, `shop.categories` |
| Client | container `backend` (FastAPI) hoặc host trong `shopnet` |

## 2. Cấu hình cố định cho từng lần chạy
